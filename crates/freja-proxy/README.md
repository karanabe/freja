# freja-proxy

Freja's HTTP/1.1 and intercepted HTTP/2, CONNECT/TLS, static TCP, SOCKS5, and
bounded HTTP repeat data-plane engines. Enable the `pingora-adapter` feature for
the optional Pingora `ServerApp` adapter.

See the [API documentation](https://docs.rs/freja-proxy) and the
[engine boundary](https://github.com/karanabe/freja/blob/master/docs/src/content/docs/developer/adr/0001-engine-boundary.md).
