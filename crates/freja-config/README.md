# freja-config

Typed loading, validation, and compilation of Freja configuration before the
data plane opens listeners.

See the [API documentation](https://docs.rs/freja-config) and the
[configuration reference](https://github.com/karanabe/freja/blob/master/docs/src/content/docs/reference/configuration.md).
